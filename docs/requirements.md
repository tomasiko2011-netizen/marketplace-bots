# ТЗ: skladprobot (Kaspi демпинг-бот)

## Цели
- Автоматизировать удержание позиций в карточках за счет корректировки цен.
- Автоматический цикл обновления по базовому интервалу (2 минуты) и турборежиму (30 секунд).
- Безопасные лимиты цен и полная история действий.

## Основной сценарий
1. Получить текущие цены конкурентов по товарам.
2. Сравнить с собственной ценой и позицией в карточке.
3. Применить правила.
4. Отправить обновленные цены через официальный API.
5. Зафиксировать изменения в истории.
6. Повторять цикл каждые 2 минуты (по умолчанию) или каждые 30 секунд в турборежиме.

## Функции
- Автоснижение цены в Kaspi.
- Быстрая реакция: 2 минуты по умолчанию, 30 секунд в турборежиме.
- Личный кабинет для управления товарами и правилами.
- Гибкие настройки стратегии.
- Поддержка нескольких магазинов.
- Исключение товаров из демпинга.
- Исключение конкурентов.
- Безопасные границы цен.
- История цен и изменений.

## Правила и ограничения
- Только официальный API.
- Нельзя изменять товары, исключенные из демпинга.
- Логи обязательны для каждого изменения.

## Настройки (минимум)
- Шаг снижения цены.
- Минимальная цена.
- Максимальная цена.
- Список исключенных товаров.
- Список игнорируемых конкурентов.
- Интервал обновления (по умолчанию 2 минуты).
- Турборежим (30 секунд).

## Метрики
- Количество изменений цен за период.
- Время реакции.
- Доля товаров в топ-3 карточки.
